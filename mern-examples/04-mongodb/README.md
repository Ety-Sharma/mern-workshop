# Part 4: MongoDB (through Express)

You learn MongoDB by using it inside an Express API. Before running anything:

1. Finish `02-atlas-setup.md` and create a `.env` file in THIS folder (copy `.env.example`).
2. In a terminal inside this folder run each example, for example `node 05-create.js`.
3. Test with `../03-express/08-testing-with-postman/requests.http` (same URLs, port 5000).

Shared files: `db.js` (connection), `Job.js` (model), `errorHandler.js` (turns database errors into 400/404 answers).
