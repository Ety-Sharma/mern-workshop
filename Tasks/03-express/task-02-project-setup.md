# Task 2: Project setup

Time: about 25 minutes. Read first: `mern-examples/03-express/02-project-setup/README.md`

## What to do

1. Create `placement-tracker/server`. This is your real project, you will use it for all Express and MongoDB tasks.
2. Run `npm init -y`, install `express cors dotenv morgan`, install `nodemon` as dev dependency.
3. Add `"type": "module"` and the `dev` script. Create `.gitignore` (node_modules and .env).
4. Run `git init`, `git add .`, `git commit -m "server setup"`.

## Expected result

`git status` shows a clean working tree, and `git log` shows your commit.

## Hint

Follow the README in the example folder step by step.

## Done when

- [ ] package.json lists all 5 packages
- [ ] node_modules is NOT in the commit
- [ ] First commit exists
