# Task 1: What Node.js is

Time: about 10 minutes. Read first: `mern-examples/02-node/01-what-is-node/hello.js`

## What to do

1. Create a folder `node-practice` and a file `hello.js` inside it.
2. Print your name, then print the Node version using `process.version`.
3. Print `typeof window` and write a comment saying why it is `undefined`.
4. Run with `node hello.js`. Then type just `node` in the terminal and try `2 + 2` and `[1,2,3].map(n => n * 2)`.

## Expected result

Something like:
```
Asha
v22.x.x
undefined
```

## Hint

`window` exists only in browsers. Node has no browser.

## Done when

- [ ] hello.js runs from the terminal
- [ ] You tried the Node prompt (exit with Ctrl + C twice)
