# Task 1: What React is, and setup

Time: about 25 minutes. Read first: `mern-examples/05-react/README.md`

## What to do

1. From the `placement-tracker` folder run `npm create vite@latest client -- --template react`, then `cd client`, `npm install`, `npm run dev`.
2. Delete everything inside `App.jsx` and show an `h1` with your name and `Placement Tracker`.
3. Delete `App.css` and the starter styles you do not need.
4. Keep your Express server running in another terminal.

## Expected result

http://localhost:5173 shows your heading and updates when you save.

## Hint

You now have two folders (`client` and `server`) and two terminals.

## Done when

- [ ] Vite app runs
- [ ] Heading shows your name
- [ ] Server still runs
