# Task 2: JSX, components and props

Time: about 25 minutes. Read first: `mern-examples/05-react/src/examples/Ex02_Props.jsx`

## What to do

1. Create `src/components/JobCard.jsx` that takes props `company`, `ctc` and `status` and shows them in an `li`.
2. In `App.jsx` render three `JobCard`s with different props inside a `ul`.
3. Show a heading `Jobs in Gurugram` using a JavaScript variable inside `{ }`.

## Expected result

Three job cards on the page.

## Hint

Component names start with a capital letter. Use `className` not `class`.

## Done when

- [ ] JobCard is a separate file
- [ ] Three cards render
