# Task 6: Loops

Time: about 20 minutes. Read first: `mern-examples/01-javascript/06-loops.js`

## What to do

1. Open `task-06-loops.js`.
2. Use a `for` loop to print the numbers 1 to 10.
3. Use `for...of` to add up the `marks` array and print `total 323`.
4. Use `for...of` with an `if` to print only the marks above 50 as `above 50: 67`.
5. Use a `while` loop to count down from 5 to 1 as `countdown 5` ... `countdown 1`.

## Expected result

```
1
2
...
10
total 323
above 50: 67
above 50: 89
above 50: 90
countdown 5
countdown 4
countdown 3
countdown 2
countdown 1
```
(The dots mean the numbers 3 to 9 are printed too.)

## Hint

Start `let total = 0` before the loop and use `total += m` inside it. In the `while` loop do not forget `n--`, or it never stops (Ctrl + C).

## Done when

- [ ] Output matches
- [ ] Your while loop ends
