# Task 1: Variables and data types

Time: about 10 minutes. Read first: `mern-examples/01-javascript/01-variables.js`

## What to do

1. Open `task-01-variables.js` and fill in the TODO lines.
2. Print the sentence with a template literal.
3. Change the age (it is a `let`) and print the sentence again.
4. Print the type of each variable with `typeof`.

## Expected result

```
Ravi is 19 years old and lives in Palwal
Ravi is 20 years old and lives in Palwal
string number boolean
```

## Hint

Use backticks and `${name}` inside the text. Only `let` variables can be changed.

- [ ] Output matches exactly
- [ ] You used `const` for values that do not change
