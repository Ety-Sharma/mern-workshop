# Task 1: What MongoDB is

Time: about 10 minutes. Read first: `mern-examples/04-mongodb/01-what-is-mongodb.md`

## What to do

1. Create `docs.json` containing an array of three job documents.
2. Give the third one an extra field `remote: true` that the others do not have.
3. Write 3 lines in `notes.txt`: SQL vs MongoDB (table, row, column compared with collection, document, field).

## Expected result

Three documents, and one has an extra field. This is what "flexible schema" means.

## Hint

Documents look like the JavaScript objects you already know.

## Done when

- [ ] docs.json is valid JSON
- [ ] notes.txt has the comparison
